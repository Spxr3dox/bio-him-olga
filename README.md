# Персональний сайт репетитора — Ольга Журавель

Односторінковий сайт (лендинг) для підготовки до НМТ з хімії та біології.
Реалізовано за технічним завданням: чистий HTML/CSS/JS, **без форм і полів вводу** —
усі заклики до дії ведуть на дзвінок або в месенджери.

## Структура файлів

```
index.html                    — уся сторінка (5 блоків за ТЗ)
assets/css/style.css          — стилі, палітра, адаптивність
assets/js/main.js             — меню, поява блоків, анімований фон «зв'язків»
assets/img/olga-zhuravel.jpg  — фото викладача
assets/img/favicon.svg        — іконка сайту
robots.txt, sitemap.xml       — для пошукових систем
photo_2026-09-03_14-22-55.jpg — вихідне фото (оригінал, не використовується сайтом)
```

## Запуск

Просто відкрийте `index.html` у браузері — збірка не потрібна.
Для публікації скопіюйте всі файли в кореневу папку хостингу (`public_html`, Netlify, GitHub Pages тощо).

## Ключові технічні рішення за ТЗ

- **Click-to-call:** усі номери огорнуті в `<a href="tel:+380680772607">` (8 посилань).
- **Закріплена шапка:** `position: sticky` — номер і кнопка «Зателефонувати» завжди на екрані.
- **Мобільна панель:** знизу екрана на телефонах закріплена велика кнопка дзвінка + Telegram/Viber.
- **Жодних форм:** на сторінці немає `<form>`, `<input>`, `<textarea>`, `<select>`.
- **Месенджери:** `https://t.me/…` та `viber://chat?number=…`.

## Підтримка браузерів

Chrome/Edge/Firefox/Safari останніх версій, iOS Safari 15+, Android Chrome.
Використано `color-mix()` (Chrome 111+, Safari 16.2+); у старіших браузерах кольори
просто відображаються менш насиченими, верстка не ламається.
Анімації автоматично вимикаються при системному налаштуванні «зменшити рух».
